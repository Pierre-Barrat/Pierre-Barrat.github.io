# Pierre Barrat, BTS SIO option SISR

Site de présentation de mon parcours, de mes compétences et de mes projets.

Voir le site : https://pierre-barrat.github.io/

## Compléter le site

- Les endroits à compléter sont signalés par des commentaires dans les fichiers HTML (CV, LinkedIn, captures d'écran, fiches de veille, nouvelles compétences).
- Pour afficher un élément commenté, supprimez les marques `<!--` et `-->` qui l'entourent.
- Le CV se dépose dans `assets/cv/cv.pdf`, les images dans `assets/img/`.
- Les couleurs se changent en haut de `style.css`, dans le bloc `:root`.
- Polices : Bricolage Grotesque et Source Serif 4, sous licence SIL Open Font License.
